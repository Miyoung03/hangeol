한결 r12 - 마지막 r11 디자인에서 요청한 부분만 수정

1. 처음에는 항목이 자동 등록되지 않습니다.
2. 설정 > 항목 추가에서 원하는 모노라인 아이콘을 선택하면 해당 항목이 추가됩니다.
3. 항목명 입력창은 제거했습니다. 선택한 아이콘의 항목명(봉사·공부·운동 등)이 자동 사용됩니다.
4. 기존에 기록 또는 목표를 가진 항목은 유지합니다. 이전 버전에서 기본 생성됐으나 미사용·미설정인 항목만 최초 업데이트 때 정리합니다.
5. 기존 r11 헤더·누적시간 카드·홈 화면 아이콘·통계·기록 등 나머지 디자인은 유지합니다.
