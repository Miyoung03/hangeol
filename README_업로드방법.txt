한결 앱 아이콘 수정 r10

적용한 내용
- 봉사: 기본형 가방(손잡이가 있는 심플한 토트백) SVG 아이콘으로 변경
- 아이폰 홈 화면: 이전에 선택하신 1번 시간의 축적(원형 시간 진행) 아이콘 적용
- 공부·운동·독서·기타 아이콘 및 기록·통계 기능은 변경하지 않음
- 캐시 버전 r10 적용

GitHub Pages 적용
1. ZIP 압축을 풀어 파일 모두 GitHub 저장소 최상위 경로에 덮어쓰세요.
2. GitHub Pages 배포 완료 후 Safari에서 새로 고침합니다.
3. 홈 화면 아이콘이 그대로라면 Safari에서 확인한 후 기존 홈 화면 바로가기를 삭제하고 다시 추가해야 새 아이콘으로 바뀔 수 있습니다.
4. 앱을 삭제하기 전 기록 백업을 권장합니다. 같은 주소/저장 영역을 이용하면 기록은 유지되지만, 홈 화면 앱 저장소가 삭제될 수 있습니다.
5. 앱 설정 하단의 "앱 버전 r10"으로 화면 코드 갱신 여부를 확인하세요.


[r11 추가 변경]
